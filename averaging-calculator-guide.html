계산기 이용법 FAQ 소개

주가가 떨어졌을 때 추가로 매수(물타기)하거나, 반대로 오르는 중에 더 매수(불타기)하면 평단가가 어떻게 바뀌는지 궁금할 때가 있습니다. 물타기 계산기는 현재 보유 정보와 추가 매수 정보만 입력하면 새 평단가와 본전까지 필요한 상승률을 바로 계산해드립니다. 쓰는 법은 아래와 같습니다.

  1. 현재 보유 정보 입력

    지금 계좌에 있는 평단가와 보유 수량을 입력하세요.

    현재 보유 정보 입력 화면

  2. 추가 매수 정보 입력

    추가로 살 단가와 수량을 입력하세요. "+ 매수 추가" 버튼을 누르면 2차, 3차까지 나눠서 살 계획도 한 번에 시뮬레이션할 수 있습니다. 매매수수료·거래세를 알고 있다면 "매매수수료·세금 반영" 항목을 펼쳐서 입력할 수도 있습니다(선택사항).

    추가 매수 입력 화면

  3. 새 평단가와 본전 탈출 상승률 확인

    추가 매수를 반영한 새 평단가와 총 투자금액·총 보유수량, 그리고 본전 탈출에 필요한 상승률이 바로 나옵니다. 이 상승률은 가장 마지막에 입력한 매수 단가(현재 주가로 가정)를 기준으로 계산됩니다.

    결과 화면 (70,000원 100주 → 50,000원 100주 추가매수 예시)

  4. 목표 평단가 역산 계산기 활용

    원하는 평단가를 직접 입력하면, 현재 보유 정보와 마지막 매수 단가를 기준으로 몇 주를 더 사야 그 평단가에 도달하는지와 필요한 금액을 역산해서 보여줍니다.

    목표 평단가 역산 결과 화면 (목표 58,000원 예시)

계산 기준

새 평단가는 가중평균 방식(기존 투자금액 + 추가 매수금액을 총 보유수량으로 나눈 값)으로 계산합니다. 매매수수료·세금은 기본값이 0%이며, 입력하면 더 정확한 본전 탈출 상승률을 계산할 수 있습니다.

계산은 참고용이며 투자 조언이 아닙니다.

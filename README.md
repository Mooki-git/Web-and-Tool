# 재테크 계산기 미니사이트

프레임워크 없이 순수 HTML / CSS / JavaScript로 만든 정적 사이트입니다.
GitHub에 올리면 Vercel이 자동으로 배포합니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (질문·결과·FAQ) |
| `style.css` | 디자인 (다크모드·모바일 대응 포함) |
| `script.js` | 계산 로직 및 실시간 화면 갱신 |

## 계산기 목록

### 1. ISA 절세 효과 계산기 (`/`)

투자수익과 소득 정보를 입력하면 ISA 가입 유형을 자동 판정하고,
일반 계좌 대비 절세액을 원화로 계산합니다.

**계산 기준 — 조세특례제한법 제91조의18 (2026.08 확정)**

| 항목 | 값 |
|---|---|
| 비과세 한도 (일반형) | 200만원 |
| 비과세 한도 (서민형·농어민형) | 400만원 |
| 한도 초과분 세율 | 9.9% 분리과세 (소득세 9% + 지방소득세 0.9%) |
| 일반 계좌 세율 | 15.4% (소득세 14% + 지방소득세 1.4%) |
| 서민형 자격 (근로소득자) | 총급여 5,000만원 이하 |
| 서민형 자격 (사업·기타소득자) | 종합소득금액 3,800만원 이하 |
| 가입 제한 | 금융소득종합과세 대상자(연 금융소득 2,000만원 초과) 가입 불가 |
| 의무가입기간 | 3년 (전 유형 동일) |

세율이나 한도가 바뀌면 `script.js` 맨 위의 `RULES` 상수만 수정하면 됩니다.

> **참고:** 2027년 1월 1일 신규 가입분부터 기존 ISA에 계약기간 5년 제한이 생기고
> "생산적금융 ISA"가 별도 신설될 예정입니다. 현재 계산에는 반영하지 않았습니다.

#### 계산 방식

```
ISA 과세대상   = max(0, 투자수익 − 손실)          ← 손익통산 적용
ISA 세금       = max(0, ISA 과세대상 − 비과세한도) × 9.9%
일반계좌 과세대상 = 투자수익                        ← 손익통산 안 됨
일반계좌 세금  = 투자수익 × 15.4%
절세액         = 일반계좌 세금 − 판정된 유형의 ISA 세금
```

## 로컬에서 확인하기

별도 설치 없이 `index.html` 파일을 브라우저로 열면 됩니다.
간이 서버로 띄우려면:

```bash
npx http-server -p 8080
```
